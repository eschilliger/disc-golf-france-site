## Mise en ligne sur GitHub Pages
1. Crée un dépôt GitHub public, par exemple `disc-golf-france-site`.
2. Ajoute ces fichiers à la racine du dépôt.
3. Sur GitHub, ouvre **Settings > Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Branche : `main`, dossier : `/ (root)`.
6. Enregistre.
7. GitHub fournira une URL du type :
   `https://TON-PSEUDO.github.io/disc-golf-france-site/`
